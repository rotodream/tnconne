プロフィール コネクト v12 + D1/R2 Worker Project
==================================================

目的
----
完成済みの画面・入力フォーム・管理者ページを作り直さず、
「相手から送信されたプロフィール」だけをCloudflare側に永続保存します。

保存先
------
文字・選択項目: D1
写真: R2

Cloudflare側で追加するバインディング
-----------------------------------
D1
  変数名（Binding name）: DB
  データベース: my-app-db

R2
  変数名（Binding name）: BUCKET
  バケット: my-app-images

重要
----
wrangler.jsonc には Worker入口(index.js) と static assets(public/) の関係を入れています。
D1/R2の実体との紐付けは、Cloudflareダッシュボードの
「バインディングを追加」画面で上記2つを指定してください。

D1のdatabase_idはアカウント固有値なので、推測してZIPへ書き込んでいません。
Cloudflareダッシュボードから紐付ける方式ならdatabase_idを手入力する必要はありません。

既存3件
-------
Chrome引継ぎZIPに入っていた受信済みプロフィール3件を初回起動時にD1へ移します。
写真データがある場合はR2へ移します。

管理者
------
既存の管理者画面とボタンはそのままです。
初回のサーバー側管理者パスワードは monogatari2026 です。
既存の「管理者パスワード変更」画面から変更できます。

変更していないもの
------------------
・トップ画面
・相手側の入力フォーム
・確認画面
・管理者ページの見た目
・CSV/PDF
・管理者のプロフィール編集
・事業項目編集
・引継ぎZIP保存機能

変更した部分
------------
・相手の最終送信先 → D1/R2
・管理者の受信プロフィール一覧 → D1/R2から読み込み
・受信プロフィール削除 → D1/R2から削除
・管理者パスワード → D1へ安全なハッシュで保存
